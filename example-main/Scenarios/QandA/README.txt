#
# サンプルシナリオ：一問一答式の対話を行う
#
・使用している機能
  * 基本的な fst の書き方
  * 新たなモデル（.pmd）の表示と消去（MODEL_ADD，MODEL_DELETE）
  * 別のモデルへの交代（MODEL_CHANGE）
  * ウィンドウにキーを押した情報を送る（KEY_POST）

・受け付ける発話
  - こんにちは
  - さようなら
  - あなたは誰ですか？
  - 大学の図書館はどこですか？
  - ありがとう
  - 可愛いね
  - フルスクリーンにして
  - スクリーンの設定を戻して
  - 別の人になって
  - 英語を話して
