## 1. ⚠️ 注意事項：Googleアカウントについて

> **【最重要】大学のアカウントは使用できません**
> 
> 大学のGoogleアカウント（`@...ac.jp` や `@...edu` など）ではAPIキーが作成できません。  
> 組織のセキュリティ制限により「Google AI Studio」へのアクセスが制限されているためです。
> 
> **👉 必ず「個人のGoogleアカウント（`@gmail.com`）」を使用してください。**

---

## 2. 🔑 Gemini APIキーの取得

1. ブラウザで **[Google AI Studio](https://aistudio.google.com/)** にアクセスします。
2. **個人のGoogleアカウント**でログインします。
3. 利用規約が表示された場合は、内容を確認し同意（Check）して進みます。
4. 画面内にある **「Get API key」**（または「Create API key」）をクリックします。
5. **「Create API key in new project」** を選択します。
6. 発行された `AIzaSy...` から始まる文字列（APIキー）をコピーし、メモ帳等に一時保存しておきます。

> ⚠️ **取扱注意**  
> APIキーはパスワードと同じです。LINEやDiscord、Slackなどのチャットに貼り付けたり、人に教えたりしないでください。

## 3. 🛡️ .gitignore ファイルの作成

APIキーを誤ってGitHub等のリモートリポジトリに送信（push）しないためのセキュリティ設定です。

1. VS Codeでプロジェクトの一番上のフォルダ（`example-main` 直下）を開きます。
2. フォルダ直下に**新規ファイル**を作成します。
3. ファイル名を **`.gitignore`** にします。
   * **※注意:** 先頭にドット（`.`）が必要です。末尾に `.txt` などの拡張子はつけないでください。
4. 作成した `.gitignore` に以下を書き込んで保存（`Ctrl + S`）します。

```gitignore
.env
__pycache__/
*.pyc
